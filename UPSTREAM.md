# Upstream attribution

Qoralis Engine is a downstream distribution of [Colibri](https://github.com/JustVugg/colibri), originally created by Vincenzo Fornaro (JustVugg).

The upstream Apache-2.0 license, copyright notices, and third-party licenses are retained. Qoralis changes branding, packaging, documentation, launch aliases, and selected interface assets. The original colibri Python import namespace and coli command remain for backward compatibility.

Qoralis is an independent downstream project and is not affiliated with or endorsed by the upstream author.
